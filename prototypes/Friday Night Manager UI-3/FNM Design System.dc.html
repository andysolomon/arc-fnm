Responsive & interaction-complete (Phase 8)
How the prototype reflows at 1440 / 1024 / 768 / 390, and how dead-looking controls were retired.
Reflow, not scaling
  • Below 900px the sidebar becomes a scrimmed drawer and the Continue label shortens; blockers stay red.
  • Rails are flex-wrap rows with flex-basis, never fixed grid columns — secondary rails stack under the primary decision.
  • Dense tables (Squad, Academics, Schedule) sit in a contained horizontal scroller with a min-width track; the page itself never scrolls sideways.
  • Field diagrams keep their 520px geometry inside their own scroller so drop targets never overlap.
  • Display numerals use clamp() (scoreboard 30–48px); nothing is shrunk wholesale.
  • Inbox goes single-pane below 900px — list, then message with an “← All messages” return.
Retiring dead controls
  • Acknowledged action — a taken message action re-labels in the past tense and greys (“Tape queued with Soto”).
  • Disabled-with-reason — a control either acts or states its reason in place (Full Profile outside Reed; coordinator dials set by the scheme).
  • Deferred state — “Later” resolves to a visible “Deferred · Nov board” status, never silence.
  • Selections (rows, scheme cards, RT options) are real buttons with aria-pressed and the focus ring; drags keep a click path.
  • Reset Week restores the full seeded baseline, scheme choices included.
Rules
  • Spacing on a 4px grid: 8 / 12 / 16 / 24 / 32 / 48. Separate with space, not divider lines.
  • Radius: 6px components · 12px cards · 9999px pills. Nothing larger on functional UI.
  • Weight 600 for display headings only; 500 for emphasis; never 700.
  • Negative letter-spacing ≈ -4% at 16px+; normal tracking at body sizes.
  • Blue #0072F5 = interactive/active only. Field diagrams, charts and surfaces stay achromatic.
  • Hover changes background/color only — no transform, no opacity fades.
  • Status meaning is never carried by color alone — every dot is paired with a word.
  • Every visible control navigates, changes state, or explains why it is disabled. Nothing decorative.
  • Derived values name their inputs in place. No opaque composite scores.
