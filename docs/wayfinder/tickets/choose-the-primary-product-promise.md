# Choose the primary product promise

## Question

Is the first product principally a decision-training game for aspiring and active coaches, an operational tool that real programs use during a live season, or a deliberately sequenced path from the former to the latter?

## Resolution

Build both as a deliberate sequence. Launch the Simulation Experience first so coaches, staffs, and the broader football audience can have fun inhabiting the coach or executive fantasy and so the core decisions can be learned without integration dependencies. Build the Program Workspace second as the higher-value operational product for real staffs; it may reuse the Decision Model, but live integrations and protected program data must not block or contaminate the simulation product.
