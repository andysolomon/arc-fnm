# Build the simulation first and share only the Decision Model

Friday Night Manager will deliver a broad Simulation Experience first and a live Program Workspace second. The experiences may share football language and the Decision Model, but simulated careers and live program/student data will remain separate security and data contexts; this keeps integration and privacy complexity from blocking the first release while preserving a path to the higher-value operational product. Live-record controls for that second experience are in [ADR 0003](./0003-program-workspace-live-data-controls.md). Non-canonical Friday generation is in [ADR 0004](./0004-arc-sim-friday-adapter.md).
